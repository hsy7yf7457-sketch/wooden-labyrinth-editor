    GitHub repository

    Personal access token

    A token is required to save packs. It's stored only in this browser (localStorage). Reading packs from a public repo works without a token.

    How do I create one?
    1. Open github.com/settings/personal-access-tokens and click Generate new token (fine-grained).
    2. Resource owner: your user. Repository access: Only select repositories → pick this editor's repo.
    3. Permissions → Repository permissions → Contents: Read and write.
    4. Generate, copy the token, paste it above, click Save settings.
